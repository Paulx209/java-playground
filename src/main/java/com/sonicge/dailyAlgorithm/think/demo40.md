* 【有效的括号】
* 给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。
* 有效字符串需满足：
* 左括号必须用相同类型的右括号闭合。
* 左括号必须以正确的顺序闭合。
* 每个右括号都有一个对应的相同类型的左括号。
*
* 输入：s = "()[]{}"
* 输出：true

思路：

1.首先对第一个字符进行特判，如果第一个字符为) } ]的话，就直接return false

2.然后遍历所有的括号字符，如果是( { [ 的话就直接入栈；如果不是的话，先判断栈是否为空，如果不为空的话，需要判断是否和栈顶的元素对应！

比如说如果当前的元素为]，那栈顶的元素必须为[，否则就是不对应，不对应之后直接return 即可
