* [有效的数独]
* 请你判断一个 9 x 9 的数独是否有效。只需要 根据以下规则 ，验证已经填入的数字是否有效即可！规则如下：
* 1.大矩阵中一行和一列中的数字必须为1 -> 9，且不能出现重复的数字
* 2.小矩阵为3*3，格子中不能出现重复的数字

思路：

我认为大矩阵的判断方式比小矩阵的判断方式简单，所以我们先判断大矩阵是否满足，然后再判断小矩阵是否满足。

1.大矩阵只需要通过两层遍历循环，然后每一行用一个HashMap存储出现过数字的次数，如果!=0的话，就说明出现过重复的数字了，直接return false

2.小矩阵的话也是通过两层遍历循环，但是我们提前要定义9个小矩阵格子，然后去判断每一个格子属于哪一个矩阵，然后在获取到矩阵对应的HashMap，然后判断该元素是否出现过。
