* n 个孩子站成一排。给你一个整数数组 ratings 表示每个孩子的评分。
* 你需要按照以下要求，给这些孩子分发糖果：
* 每个孩子至少分配到 1 个糖果。
* 相邻两个孩子中，评分更高的那个会获得更多的糖果。
* 请你给每个孩子分发糖果，计算并返回需要准备的 最少糖果数目 。
*
* 输入：ratings = [1,0,2]
* 输出：5
* 解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。

思路：
由于要求每个孩子至少分配到1个糖果，并且相邻两个孩子中，评分更高的会获取更多的糖果。所以只要实现了这个规则，就意味着我们可以计算出最少的糖果
1.先从左遍历，本次不算下标为0的小孩（因为左边没人了）。如果左边小孩的评分低于他的话，他的糖果个数为：candies[i-1] + 1 ； 如果高于它的话，他的糖果个数为1
2.然后继续从右遍历，不计算下标为size-1的小孩（因为右边没人了）。如果右边小孩的评分低于他的话，他的糖果个数为candies[i+1]+1；如果高于他的话，糖果个数为1

现在有两个数组，分别是满足这个规则所需要的糖果数，那为了两边都满足，我们只可以取出来最大的那个数，累加即可。
