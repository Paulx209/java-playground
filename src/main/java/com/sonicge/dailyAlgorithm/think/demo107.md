# 【380. O(1) 时间插入、删除和获取随机元素】

实现RandomizedSet 类：

RandomizedSet() 初始化 RandomizedSet 对象

bool insert(int val) 当元素 val 不存在时，向集合中插入该项，并返回 true ；否则，返回 false 。

bool remove(int val) 当元素 val 存在时，从集合中移除该项，并返回 true ；否则，返回 false 。

int getRandom() 随机返回现有集合中的一项（测试用例保证调用此方法时集合中至少存在一个元素）。每个元素应该有 相同的概率 被返回。

你必须实现类的所有函数，并满足每个函数的 平均 时间复杂度为 O(1) 。
思路：

1. 要保证插入、删除、随机获取一个元素的时间复杂度是O(1)，就要利用不同数据结构的特性，插入：哈希表在插入时平均时间复杂度为O(1)；删除：这里我们可以依赖数组的删除，但是只删除最末尾的元素。Random:随机获取，基于数组的地址值获取 or 基于hash的哈希获取，平均时间复杂度都是O(1)

2. insert()方法的实现，通过map来判断是否存在val元素，平均时间复杂度为O(1)；插入基于list.add()，时间复杂度为O(1)。

3. remove()方法的实现，借助list.removeLast()来实现，普通的删除会涉及后面元素下标的重置，因此我们这里通过删除最后一个元素来保证时间复杂度为O(1)，然后将要删除元素所在的下标替换为最后一个元素的值，list和map都要做对应的措施。
