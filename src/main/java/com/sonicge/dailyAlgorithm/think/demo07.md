* 给定一个长度为 n 的 0 索引整数数组 nums。初始位置在下标 0。
* 每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在索引 i 处，你可以跳转到任意 (i + j) 处：
* 0 <= j <= nums[i] 且
* i + j < n
* 返回到达 n - 1 的最小跳跃次数。测试用例保证可以到达 n - 1。
* 输入: nums = [2,3,1,1,4]
* 输出: 2
* 解释: 跳到最后一个位置的最小跳跃数是 2。 从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。

思路：

第一轮，maxRange=nums[i]，可以到达最远的距离为nums[i]，在0->nums[i]遍历的过程中，找到这个范围里面最远可以到达的下标，然后cur=maxRange

第二轮，cur变量其实就是记录上一轮可以跳到的最远下标，在i到达cur的时候，一直更新maxRange

这样就可以实现最小次数到达末尾。先知道上一轮可以跳到的最远距离，然后在遍历到最远距离的时候，更新这一轮的最远距离。只要能到达末尾了，就直接停止继续找。
