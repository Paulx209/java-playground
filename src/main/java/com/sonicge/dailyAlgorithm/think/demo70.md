* 【寻找旋转排序数组中的最小值】
* 已知一个长度为 n 的数组，预先按照升序排列，经由 1 到 n 次 旋转 后，得到输入数组。例如，原数组 nums = [0,1,2,4,5,6,7] 在变化后可能得到：
* 若旋转 4 次，则可以得到 [4,5,6,7,0,1,2]
*
* 给你一个元素值 互不相同 的数组 nums ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 最小元素 。
* 你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。
*
* 输入：nums = [3,4,5,1,2]
* 输出：1
* 解释：原数组为 [1,2,3,4,5] ，旋转 3 次得到输入数组。

思路：

1.旋转之后，肯定会存在两部分，一部分高台阶，一部分低台阶，比如说[4 5 6 7 1 2 3] 左边高台阶中的所有值 都比 右边地台阶中的值大

2.如果nums[mid] >= nums[right]的话，说明mid在高台阶上，那最小值在mid的右边，但是mid的右边也可能包含高台阶

3.如果nums[mid] < nums[right]的话，说明mid在低台阶上，那最小值就在mid的左边，可能会包含mid。

补充：除了最坏情况（没有旋转）的话，**最右边的值一定是在低台阶中**
