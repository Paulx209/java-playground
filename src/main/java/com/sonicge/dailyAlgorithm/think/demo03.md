* 删除有序数组中的重复项 II
* 给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。
* 不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。
* 输入：nums = [1,1,1,2,2,3]
* 输出：5, nums = [1,1,2,2,3]

思路：
仍然使用双指针，思路和上一题大致一样，但是题目中要求重复出现的元素只能出现两次，所以判断的条件发生变化了。
slow指针仍然最终返回元素的下标，slow变化 代表 这个元素确定是要最终返回的 ；fast指针仍然是往前探测的。
1.由于前两个元素一定会保留，无论是重复还是不重复，所以slow 和 fast 的起始值设定为2

2.如果nums[fast] == nums[slow-2]，代表重复的元素超过2个，直接跳过，不更新slow下标以及对应的值

3.如果nums[fast] != nums[slow-2]，说明这个元素和已存储的元素不发生重复，可以更新slow的下标以及对应的值，但是顺序为先更新对应的值，再更新下标。

eg：
1 1  1 2 2 3。
nums[slow-2] 为 1 ; nums[fast] 为 1 ; 相等跳过 fast++   1 1 

nums[slow-2] 为 1 ; nums[fast] 为 2 ; 不相等更新,       1 1 2 

nums[slow-2] 为 1 ; nums[fast] 为 2 ; 不相等更新,       1 1 2 2

nums[slow-2] 为 2 ; nums[fast] 为 3 ; 不相等更新,       1 1 2 2 3
