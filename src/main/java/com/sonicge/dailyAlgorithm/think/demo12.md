* 给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
* 输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
* 输出：6
* 解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。

思路：
要使用柱子接雨水的话，要求该柱子左右两边有高的柱子，有的话雨水才能积累起来，没有的话雨水就漏出去了。所以我们的plan主要分为两步。
1.第一步，计算出节点左右两边最高的柱子高度。遍历数组，计算出每一个节点左边最高的柱子高度，计算出每一个节点右边最高的柱子高度。
2.第二步，计算雨水。遍历数组（第一个和最后一个柱子无需遍历），获取左右两边最高的柱子，然后取出一个min。和当前柱子的高度进行比较，大的话，就可以积累；小的话，就漏了。
