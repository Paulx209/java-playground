* 【完全二叉树的节点个数】
* 给你一棵 完全二叉树 的根节点 root ，求出该树的节点个数。
* 完全二叉树：如果一个节点的左节点为null的话，那么右节点一定为null；如果左节点不为null的话，右节点可能为null
* 也就是说节点的排序优先级 左 > 右

思路：

最开始的时候我是没有思路的， 不知道应该如何做这道题。但是看了下之前的提交了记录，又感觉比较简单了

1.首先我们要做判断，如果它是一个满二叉树的话，直接调用公式计算节点的个数即可；如果他不是一个满二叉树的话，是需要计算左右子数的节点的

2.那么如何判断是否为满二叉树呢，根据左右子树的最大高度，如果高度相同的话，说明是满的；如果不相同的话，就是不满的。

3.那对于不满的二叉树，如何计算呢？我们递归到一个左子树之后，他有可能是一颗满二叉树，所以继续按照对应的逻辑处理，如果不是的话，就一直递归

直到递归到叶子结点，会返回数目1的。
