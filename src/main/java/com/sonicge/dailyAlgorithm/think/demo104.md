* 【x的平方根】
* 给你一个非负整数 x ，计算并返回 x 的 算术平方根 。
* 由于返回类型是整数，结果只保留 整数部分 ，小数部分将被 舍去 。
* 注意：不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5 。
*
* 示例 1：
* 输入：x = 4
* 输出：2

思路：

1. 使用二分查找法来处理该题，left = 1 , right = x; 每次计算他们的中间值mid，然后通过 mid 和 x / mid对比

2.mid < x / mid，说明mid不是平方根 , left = mid+1 ; mid > x / mid，说明mid不是平方根，right = mid -1

3.最后还要将left * left 和 x对比，如果大于的话，我们是需要返回 left -1 的
