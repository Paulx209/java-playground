* 【分割等和子集】
* 给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。
* 输入：nums = [1,5,11,5]
* 输出：true
* 解释：数组可以分割成 [1, 5, 5] 和 [11] 。

思路：

1.这是一道01背包问题，所以我们在遍历的时候，必须先遍历物品，然后再遍历容量，并且遍历容量的时候，必须从后往前进行遍历，防止我们之前dp状态被刷新

2.首先我们先做剪枝处理，如果数组的和不为偶数的话，就直接return false掉！如果数组的和为偶数的话，/2 获取到target目标值

3.然后呢，我们的容量就是target，物品就是nums，我们就是要找到哪几个物品的容量是target！
