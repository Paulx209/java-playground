* 给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。
*
* 输入: nums = [1,2,3,4,5,6,7], k = 3
* 输出: [5,6,7,1,2,3,4]
* 解释:
* 向右轮转 1 步: [7,1,2,3,4,5,6]
* 向右轮转 2 步: [6,7,1,2,3,4,5]
* 向右轮转 3 步: [5,6,7,1,2,3,4]


思路：
这道题有一道固定的思路，思路如下。
1.就是对整个数组进行反转
2.然后在对0,k-1 ； 
3.k,size-1进行反转。

说一下这种思路为什么可以实现？
1.因为整个是向右进行轮转的，所以要对整体先旋转一次，也就是 [0,size-1]
2.然后我们的元素的一个顺序不能改变，除了首尾之间的顺序除外！所以在分割线的前后要再多旋转一次，也就是 [0,k-1] 和 [k,size-1]
