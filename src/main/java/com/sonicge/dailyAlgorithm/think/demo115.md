## 【最长有效括号】

* 给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。 
* 左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 "(()())"。

### 【输入输出用例】

示例 1：

输入：s = "(()"

输出：2

解释：最长有效括号子串是 "()"

示例 2：

输入：s = ")()())"

输出：4

解释：最长有效括号子串是 "()()"


### 【思路】

1. start变量控制左侧有效的边界，如果一个右括号没有和它对应的左括号的话，就需要更新start了！代码中对应的逻辑是：遇到右括号，并且stack为空

2. 如果遇到的是左括号的话，直接入栈，不需要考虑

3. 如果遇到的是右括号的话，需要判断当前的栈是否为空，为空的话就需要更新start了；不为空的话，说明左侧有对应的括号对应，仍有两种情况

    3.1 如果左侧除了对应的括号，没有多余的括号的话，res = Math.max(res,i - start +1)

    3.2 如果左侧除了对应的括号，还有多余的括号的话，res = Math.max(res,i - index +1 )
