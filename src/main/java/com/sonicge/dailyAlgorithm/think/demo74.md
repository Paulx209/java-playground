* 【和为k的子数组】
* 给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。
* 子数组是数组中元素的连续非空序列
*
* 输入：nums = [1,1,1], k = 2
* 输出：2

思路：

1.使用前缀和+哈希表的思路，哈希表中我们需要记录每一个前缀和出现的次数

2.举个例子 [1,2,3,4,5,6,7,8] 我们要寻找和为15的一个连续子数组

3.可以通过0->5的前缀和 - 0->2的前缀和,由于之前的前缀和我们都在hashmap中保留了，所以只需要判断是否存在0->5的前缀和 - k，存在的话，就说明有连续的子数组的和为k
