* 【最小覆盖子串】
*  滑动窗口
*  输入：s = "ADOBECODEBANC", t = "ABC"
*  输出："BANC"
*  解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

思路：

1.定义一个记账本，将t中的字符都记录上去。使用桶计数 -> ++arr[ch - 'A']

2.然后使用滑动窗口思路处理字符串s，使用一个count变量作为滑动窗口的条件，每次 --arr[ch-'A'] >=0的话,说明处理的字符是t中的字符，然后count--

3.count==0之后，就可以开始处理滑动窗口左边界了，如果左边界 ++arr[ch-'A'] >0的话，说明处理到关键字符了，再往里面缩进就不行了。此时更新res结果值（如果start 和 end变量来进行维护）
