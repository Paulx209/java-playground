# 【删除有序数组中的重复项 II】

给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

示例 1：

输入：nums = [1,1,1,2,2,3]

输出：5, nums = [1,1,2,2,3]

解释：函数应返回新长度 length = 5, 并且原数组的前五个元素被修改为 1, 1, 2, 2, 3。 不需要考虑数组中超出新长度后面的元素。

提示：该题是 26. 删除有序数组中的重复项 的进阶版

思路：

1. 先判断数组的长度，如果<=2的话，说明只有两个元素，直接返回当前的数组长度，无需处理。

2. 双指针思路处理, slow = fast = 2, 如果nums[fast] ==  nums[slow-2] 的话，就会破坏最多允许两个重复元素的条件。因此不做任何处理

3. 如果nums[fast] != nums[slow-2]的话，就要扩展slow慢指针的边界，因为此时是符合题目要求的
