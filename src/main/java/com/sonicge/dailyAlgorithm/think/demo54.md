* 【二叉树展开为链表】
* 给你二叉树的根结点 root ，请你将它展开为一个单链表：
* 展开后的单链表应该同样使用 TreeNode ，其中 right 子指针指向链表中下一个结点，而左子指针始终为 null 。
* 输入：root = [1,2,5,3,4,null,6]
* 输出：[1,null,2,null,3,null,4,null,5,null,6]

思路:有两种思路，第一种思路就是遍历出来所有的节点值，然后再重新right放一次，这样的话时间复杂度还是O(N)，但是就不是原地操作了。

思路一：

1.使用前序遍历的方式先将所有的节点值遍历出来

2.再使用一个for循环来遍历，重新置换Node节点中的左右节点，左节点为null，右节点为next


思路二：原地操作，始终坚持这样一个原则：展开为链表之后，右侧的节点会在左侧的节点之后

1.所以对于当前节点来说，先将左右子树展开为单向链表

2.然后更新右侧部分，先为左侧链表，然后再在左侧链表的最后一个的right，接上之前旧的right
