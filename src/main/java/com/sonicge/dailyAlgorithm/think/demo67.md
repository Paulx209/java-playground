* 【单词搜索】
* 给定一个 m x n 二维字符网格 board 和一个字符串单词 word 。如果 word 存在于网格中，返回 true ；否则，返回 false 。
*
* 输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
* 输出：true

思路：

1.回溯模板，但是有几个点需要我们注意一下，首先经过的点就不能再次经过了，可以将经过的节点设置成非法字符

2.然后还有一些剪枝操作：比如说最开始的时候可以判断是否和第一个字符相等，只有相等再进行开始

3.还有一个点就是：代码中使用的是index去判断，没有使用StringBuilder来拼接，在回溯的时候维护它的值相等
