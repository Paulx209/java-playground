* 【简化路径】
*  给你一串绝对路径(以'/'开头)，请你将其转化为 更加简洁的规范路径。
*  在 Unix 风格的文件系统中规则如下：
* 一个点 '.' 表示当前目录本身。
* 此外，两个点 '..' 表示将目录切换到上一级（指向父目录）。
* 任意多个连续的斜杠（即，'//' 或 '///'）都被视为单个斜杠 '/'。
* 任何其他格式的点（例如，'...' 或 '....'）均被视为有效的文件/目录名称。
*
* 一句话解释：请你将路径中所有的. , ..去除掉，并且去除多余的 / ，然后返回出来。
* 输入：path = "/home/user/Documents/../Pictures"
* 输出："/home/user/Pictures"
* 解释：两个点 ".." 表示上一级目录（父目录）。

思路：

1.先对整个字符串按照'/'分割，然后遍历分割后的数组，数组中可能会出现以下几种情况：

    a.出现空的字符串:""，说明是遇到了多个连续的'/'，对于这部分字符串直接忽略即可，直接continue
    b.出现'..'，我们要后退到上一层，因此我们使用stack栈来记录已经遍历过的路径字符串，直接删除栈顶元素即可
    c.出现'.'，我们不需要做处理，直接continue，和第一种情况一样
    d.此外出现的所有情况，都视为字符串，拼接到StringBuilder中即可
