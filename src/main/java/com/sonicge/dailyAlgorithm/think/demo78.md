# Demo78 快速排序

## 1. 这道题你到底在做什么

你要学的是“快速排序”。

它的目标很简单：

- 给你一个乱序数组
- 想办法把它排成从小到大

比如：

```text
[6, 1, 8, 3, 2]
```

排完以后就会变成：

```text
[1, 2, 3, 6, 8]
```

---

## 2. 快速排序最核心的思想

快速排序不是一上来就把整个数组直接排好。

它的思路是：

1. 先随便找一个数，当作“基准值”
2. 把数组整理一下
3. 让“比基准值小的数”都跑到左边
4. 让“比基准值大的数”都跑到右边
5. 这样基准值就到了它最终应该在的位置
6. 然后左边那一坨继续排
7. 右边那一坨继续排

你可以把它理解成：

“先把一个人放到正确座位上，再去安排他左边和右边的人。”

---

## 3. 这份代码里是怎么做的

这次我给你写的是 3 个方法：

### `main`

这个方法负责：

- 从键盘读入数组长度
- 从键盘读入每个数字
- 打印排序前数组
- 调用快速排序
- 打印排序后数组

所以你运行后，可以自己输入数据练习。

---

### `quickSort`

这个方法负责：

- 判断当前这一段数组还要不要继续排
- 如果需要，就先分区
- 然后递归处理左边
- 再递归处理右边

你可以把它理解成“总指挥”。

它自己不负责具体交换细节，它只负责：

- 划分任务
- 继续递归

---

### `partition`

这个方法是快速排序最关键的部分。

它负责做一件事：

“把基准值放到正确位置上。”

在这份代码里，我们选的是：

```text
最右边的元素
```

作为基准值。

比如数组：

```text
[6, 1, 8, 3, 2]
```

这里基准值就是：

```text
2
```

然后我们扫描前面的元素：

- 6 和 2 比，6 大，不动
- 1 和 2 比，1 小，放到左边区域
- 8 和 2 比，8 大，不动
- 3 和 2 比，3 大，不动

最后再把基准值 2 放到“小数区域”后面。

结果就会变成：

```text
[1, 2, 8, 3, 6]
```

注意：

- 这时候 `2` 已经在正确位置上了
- `2` 左边都不大于它
- `2` 右边都比它大
- 但是右边那部分还没完全有序

所以还要继续递归。

---

## 4. 递归到底是怎么回事

很多初学者卡在“递归”。

你先不要把它想得太玄。

递归本质上就是：

“大问题和小问题长得一样，所以交给同一个方法反复处理。”

比如：

```text
quickSort(nums, 0, 4)
```

先把整个数组排。

如果基准值最后落在下标 `1`，那接下来就变成：

```text
quickSort(nums, 0, 0)
quickSort(nums, 2, 4)
```

左边只有一个数，就不用排了。

右边还有多个数，就继续排。

如果以后右边又被拆成更小的两段，就继续调用自己。

这就叫递归。

---

## 5. 为什么 `left >= right` 就可以停

代码里有一句很重要：

```java
if (left >= right) {
    return;
}
```

意思是：

- 如果左下标大于右下标，说明这一段没东西
- 如果左下标等于右下标，说明这一段只有一个数

这两种情况都不需要排序。

所以直接结束。

这句叫“递归结束条件”。

如果没有它，程序会一直调用自己，最后栈溢出。

---

## 6. `partition` 里的 `i` 和 `j` 是什么

这个地方很容易懵，我给你揉碎。

### `j` 是什么

`j` 就是“扫描指针”。

它从左往右一个一个看：

- 看这个数是不是小于等于基准值

所以 `j` 的职责是：

“负责检查每个元素。”

---

### `i` 是什么

`i` 表示：

“当前小于等于基准值区域的最后一个位置。”

刚开始还没有“小数区域”，所以：

```java
int i = left - 1;
```

意思就是：

“先假装小数区域在数组左边外面。”

当你发现一个数小于等于基准值时：

1. `i++`
2. 交换 `nums[i]` 和 `nums[j]`

这样就等于把这个较小的数，扩进左边区域里。

---

## 7. 我们拿一个例子手动走一遍

数组：

```text
[4, 2, 7, 1, 3]
```

基准值选最右边：

```text
pivot = 3
```

初始：

```text
i = -1
j 从 0 开始
```

### 第 1 轮

`j = 0`

```text
nums[j] = 4
```

4 比 3 大，所以不动。

---

### 第 2 轮

`j = 1`

```text
nums[j] = 2
```

2 小于等于 3，所以：

1. `i++`，变成 `0`
2. 交换 `nums[0]` 和 `nums[1]`

数组变成：

```text
[2, 4, 7, 1, 3]
```

---

### 第 3 轮

`j = 2`

```text
nums[j] = 7
```

7 比 3 大，不动。

---

### 第 4 轮

`j = 3`

```text
nums[j] = 1
```

1 小于等于 3，所以：

1. `i++`，变成 `1`
2. 交换 `nums[1]` 和 `nums[3]`

数组变成：

```text
[2, 1, 7, 4, 3]
```

---

### 扫描结束

最后把基准值和 `i + 1` 位置交换：

交换 `nums[2]` 和 `nums[4]`

数组变成：

```text
[2, 1, 3, 4, 7]
```

这时候：

- `3` 已经在正确位置
- 左边 `[2, 1]` 继续排
- 右边 `[4, 7]` 继续排

最后整个数组就排好了。

---

## 8. 你可以把快速排序记成一句话

一句最朴素的话就是：

“先找一个基准值，把小的放左边，大的放右边，再分别排左右两边。”

如果你能记住这句话，你就已经抓住快速排序的骨架了。

## 10. 你现在最应该盯住哪几句

如果你一开始看不懂全部代码，不要慌，你先死盯这几句：

### 第一句

```java
int pivotIndex = partition(nums, left, right);
```

意思：

先把基准值放到正确位置。

---

### 第二句

```java
quickSort(nums, left, pivotIndex - 1);
```

意思：

继续处理左边。

---

### 第三句

```java
quickSort(nums, pivotIndex + 1, right);
```

意思：

继续处理右边。

---

### 第四句

```java
if (nums[j] <= pivot)
```

意思：

如果当前数比基准值小，就把它放到左边区域。

## 12. 最后一句人话总结

快速排序不难，它最难的地方不是代码多，而是“脑子里没有画面”。

你以后看这段代码时，脑子里一定要有这幅画面：

- 拿一个基准值
- 小的往左
- 大的往右
- 基准值归位
- 左边继续排
- 右边继续排

只要这个画面你有了，代码就只是把这个画面翻译成 Java。
