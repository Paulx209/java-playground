* 【编辑距离】
* 给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数  。
*
* 你可以对一个单词进行如下三种操作：
*
* 插入一个字符
* 删除一个字符
* 替换一个字符
*
* 输入：word1 = "horse", word2 = "ros"
* 输出：3
* 解释：
* horse -> rorse (将 'h' 替换为 'r')
* rorse -> rose (删除 'r')
* rose -> ros (删除 'e')

思路：

1.dp的初始化，需要将row 和 col 设置成 len1 +1  , len2 +1

2.然后第一行和第一列全部初始化为对应的长度！一个空串 和 一个 字符换，操作x次才会成为一样

3.状态转移方程为：如果str1.charAt(i) 和 str2.charAt(j) 相等的话，那么dp[i][j] = dp[i-1][j-1]

4.如果不相等的话，就需要通过编辑来让他们相等，如果是替换的话: dp[i][j] = dp[i-1][j-1]+1 ; 如果是删除的话：dp[i][j] = dp[i][j-1]+1 ;如果是新增的话：dp[i][j] = dp[i-1][j] +1

5.然后在三种操作里面，选择一个次数最小的即可
