* 【柱状图中最大的矩形】
* 给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。
*
* 求在该柱状图中，能够勾勒出来的矩形的最大面积。
*
* 输入：heights = [2,1,5,6,2,3]
* 输出：10
* 解释：最大的矩形为图中红色区域，面积为 10

思路：

1.要计算出柱状图中各个柱子的高度，就要以某一个柱子为基准，然后找到它左右两边第一个小于它的值

2.那我们的面积就是：该柱子的高度 * （右边第一个小于它的下标 - 左边第一个小于它的下标 -1 )

3.我们可以使用单调栈来进行维护，栈里面的元素是单调递增的，只要当前遍历到的元素是小于栈顶下标对应的元素的，说明栈顶下标右边第一个比他小的值的下标就找到了

4.那左边第一个比他小的值的下标就是下一个栈顶元素（因为单调栈是递增的顺序）

5.和每日温度的区别：每日温度中，我们要找到右边第一个大于栈顶元素的值，该题中是小于
