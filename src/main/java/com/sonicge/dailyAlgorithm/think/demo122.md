# 【算法名称】

最长重复子数组

https://leetcode.cn/problems/maximum-length-of-repeated-subarray/

给两个整数数组 nums1 和 nums2 ，返回 两个数组中 公共的 、长度最长的子数组的长度 。

## 【输入输出】

```text
示例 1：

输入：nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出：3
解释：长度最长的公共子数组是 [3,2,1] 。
示例 2：

输入：nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出：5
```

## 【思路】

1. 由于要求子数组必须是连续的，所以跟我们之前写过的《最长连续子序列》这道题还是有区别的， 两个dp的含义不同。
   2. 最长重复子数组中，dp[i][j] 表示 以 nums1[i-1] nums2[j-1] 结尾的最大重复子数组的长度，必须以这两个下标结尾。
   3. 最长连续子序列中，dp[i][j] 表示 在 nums1[i-1] nums2[j-1] 范围内的最大子序列的长度，可以不以这两个下标结尾，是这个范围中的最大子序列，且不要求必须连续。

2. 所以，dp的状态转移方程为：当nums1[i] == nums2[j]，dp[i+1][j+1] = dp[i][j] +1 ; 当nums1[i] != nums2[j]时，dp[i+1][j+1] = 0，只要不相等说明连续性就被打断了。

3. 补充，最长连续子序列中的dp状态转移方程为：当nums1[i] == nums2[j]，dp[i+1][j+1] = dp[i][j] +1 ; 当nums1[i] != nums2[j]时，dp[i+1][j+1] = Math.max(dp[i][j+1],dp[i+1][j])，允许不连续，所以可以往前取
