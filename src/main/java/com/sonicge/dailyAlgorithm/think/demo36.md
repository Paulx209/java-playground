* 【汇总区间】
* 给定一个  无重复元素 的 有序 整数数组 nums 。
* 区间 [a,b] 是从 a 到 b（包含）的所有整数的集合。
* 输入：nums = [0,1,2,4,5,7]
* 输出：["0->2","4->5","7"]
* 解释：区间范围是：
* [0,2] --> "0->2"
* [4,5] --> "4->5"
* [7,7] --> "7"

思路：

这道题我最开始的时候并没有想到一个很好的思路，就使用简单的模拟，但是发现条件不是少这里的就是少那里的，比较受限制。

1.其实使用一个start变量来维护开始的index是比较好的，每次遇到断掉的时候，更新start的值

2.我们只需要比较nums[i-1] 和 nums[i]-1 的值来判断是否断掉。如果断掉的话，还需要判断start 是否和 nums[i-1]相等

3.如果相等的话，说明只有一个元素；如果不相等话，说明是一个a->b 这样结构的
