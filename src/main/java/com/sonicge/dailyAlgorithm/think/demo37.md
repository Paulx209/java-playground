* 【合并区间】
* 以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。
* 请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。
* <p>
* 输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
* 输出：[[1,6],[8,10],[15,18]]
* 解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
*
思路：

1.和汇总区间的思路大致差不多，也是需要定义一个pre数组来进行维护

2.如果我们当前遍历到的数组和pre数组满足这样的关系时：pre[1] >= nums[i][0]，就说明有一个合并的区间，那合并之后的范围就是Math.max(pre[1],nums[i][1])

3.然后如果不满足这样的关系的话，就说明不需要重叠了，那我们只需要将此时的pre添加到res中，然后更新pre为当前遍历到的数组即可
