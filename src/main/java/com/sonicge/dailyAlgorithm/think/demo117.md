# 【算法名称】
字符串相乘

给定两个以字符串形式表示的非负整数 num1 和 num2，返回 num1 和 num2 的乘积，它们的乘积也表示为字符串形式。

注意：不能使用任何内置的 BigInteger 库或直接将输入转换为整数。
https://leetcode.cn/problems/multiply-strings/description/

## 【输入输出】

示例：

```text
示例 1:

输入: num1 = "2", num2 = "3"
输出: "6"
示例 2:

输入: num1 = "123", num2 = "456"
输出: "56088"
```

## 【思路】

1. 题目要求不能使用任何内置的库，或者将输入转换成整数。那本题就是模拟乘数运算的过程。

2. n位数 * m位数 得到的结果基本上在 ： [n+m-1,n+m]位数之间。比如两位数乘以两位数，答案在三位数到四位数之间

2. 我们就挨个处理，有一个牛逼的公式，假如说 i j是分别遍历num1 和 num2 的指标，假如都是最后一位数，那么res[i+j+1] = (val1 * val2 + res[i+j+1]) % 10 ; res[i+j] += (val1 * val2 + res[i+j+1])/10

3. 举个例子来说明当前的公式，比如说123 * 456 ，两边都是最后一位：个位。3 * 6 = 18 ，只涉及到两位，所以末位就是8，末位前一位是进位，为1。这里的1是要累加的，不能清0。
