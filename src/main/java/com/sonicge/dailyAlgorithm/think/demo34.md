* 【字母异位词分组】
* 给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。
*
* 输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
* 输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

思路：

1.如何判断两个字符串之间是否字母异位词呢？将他们转换成字符数组，然后对字符数组排序，排序完之后创建对应的字符串

2.使用一个Map<String,List<String>>来收集结果，如果String相同的话，获取对应的List集合，将字符串添加进去

3.如果String不存在的话，就创建对应的List集合，然后往里面添加元素
