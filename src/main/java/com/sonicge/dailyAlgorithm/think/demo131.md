# 【算法名称】 有重复项数字的全排列

全排列的升级版（全排列问题中不存在重复的元素，因此不会涉及到重复的结果）

当前题目的难点在于，会涉及到重复的元素，因此最终的结果也有可能是重复的，需要在回溯的过程中做去重。

## 【输入输出】


```text
输入： [1,1,2]
返回值：[[1,1,2],[1,2,1],[2,1,1]]
```

## 【思路】

1. 回溯模板，每次都 0 开始，当 part 集合的大小和当前数组的大小相等时，收集结果。

2. **重要：重复元素的去重**，对元素提前排序，这样相等的元素就会前后排。水平方向遍历：i > 0 && nums[i-1] == nums[i]，说明当前开始的元素和上一个元素相等，当前情况就可以直接跳过了，因为该元素开头的组合都已经被添加过了。

3. 但是光写这个条件还不太够，纵向 dfs 递归时，如果遇到前后重复的元素时，也会遇到这个条件，existed[i-1] 必须是处理过才能继续，不处理过的话就见鬼了，因为是dfs下来的，前一个元素 flag = false，怎么就遍历到当前元素的？
