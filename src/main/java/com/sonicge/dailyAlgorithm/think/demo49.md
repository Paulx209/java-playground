* 【删除排序链表中的重复元素 II】
* 给定一个已排序的链表的头 head ， 删除原始链表中所有重复数字的节点，只留下不同的数字 。返回 已排序的链表 。
* 输入：head = [1,2,3,3,4,4,5]
* 输出：[1,2,5]

思路：

1.如果当前节点的下一个节点和下下一个节点都不为null的话，就开始进行比较

2.如果cur.next.val == cur.next.next.val的话，就要删除重复的元素了，即cur.next = cur.next.next

3.但是可能有连续的重复的元素，所以要使用while循环来判断，直到下一个值不相等的元素出现，这里还要多跳一次

4.最后直接返回即可
