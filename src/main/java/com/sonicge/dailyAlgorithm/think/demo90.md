* 【乘积最大子数组】
* 给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。
* 输入: nums = [2,3,-2,4]
* 输出: 6
* 解释: 子数组 [2,3] 有最大乘积 6。

思路：

1.由于数组中可能出现负数，一旦出现负数的话，和最大值相乘就变成最小值了，但是最小值和它相乘，就变为最大值了。

2.所以我们维护两个变量，一个是最小值一个是最大值，dp[i][0] -> 截止当前下标的最大值 ； dp[i][1] -> 截止当前下标的最小值；

3.如果我们遇到正数的话, dp[i][0] = Math.max(nums[i],dp[i-1][0]*nums[i]) 可能会出现dp[i-1][0]的情况，这种情况就要取nums[i]了
对于dp[i][1] = Math.min(nums[i],dp[i-1][1]*nums[i])

4.如果我们遇到负数的话，dp[i][0] = Math.min(nums[i],dp[i-1][1] * nums[i])   dp[i][1] = Math.min(nums[i],dp[i-1][0] * nums[i])
